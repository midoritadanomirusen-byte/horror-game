# 灯りを向けるな - GitHub Pages 3D Horror Prototype

PC / スマホ両対応を想定した、一人称3Dホラーの試作コードです。

## まずやること
1. `MATERIAL_PLACEMENT.md` を読む
2. 3D素材を `assets/models/` に入れる
3. BGM 20曲を `assets/audio/bgm/` に入れる
4. GitHubリポジトリへこのフォルダの中身をアップロード
5. GitHub Pagesを有効化

## 操作
- PC: WASD移動 / Shift走る / マウス視点 / E調べる
- スマホ: 左仮想スティック / 右画面スワイプ / 走る / 調べる
- 共通: 懐中電灯ON/OFF、明るさ調整

## 補足
3Dモデルが未配置でも、仮の家とおちゃーん代替形状がコード側で表示されます。
BGMが未配置の場合は無音のまま進行します。
